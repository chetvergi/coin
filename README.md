# Приложение МОНЕТКА

Приложение имитирует бросок монетки и определяет результат броска и сохраняет статистику бросков в текущей сессии.
Приложение так же позволяет настраивать вероятность выпадения того или иного результата с помощью переменных окружений.


## Установка

###  1. Клонирование репозитория

```bash
git clone https://github.com/chetvergi/coin.git
cd coin
```

###  2. Создание виртуального окружения

```bash
python3 -m venv .venv
source .venv/bin/activate
```

###  3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
python -m pip install -r requirements_dev.txt
```

###  4. Установка переменных окружений

```bash
cp .env.example .env
```
При необходимости измените переменные. Переменная "STAT_TWEAK" содержит в себе вероятность выпадения ОРЛА, выраженную в процентах

## Запуск

```bash
python -m uvicorn app:app
```

После запуска:

- приложение: http://127.0.0.1:8000
- документация: http://127.0.0.1:8000/docs
- версия: http://127.0.0.1:8000/version
- проверка рабоспособности: http://127.0.0.1:8000/health
- изменить количество монет: http://127.0.0.1:8000/quantity?qu=
- бросить монетки: http://127.0.0.1:8000/throw
- статистика бросков: http://127.0.0.1:8000/stats
- сброс статистики и количества монет до одной: http://127.0.0.1:8000/reset
